# Geophic: Globe-Based Current Affairs Tracker

**Geophic** is an intelligent web platform that revolutionizes how users consume news. Instead of scrolling through static feeds, users explore an interactive **3D globe** where "hotspots" represent trending events.

Powered by a **Large Language Model (LLM)** connected to a **Model Context Protocol (MCP) server**, Geophic dynamically fetches, verifies, and summarizes real-time news from multiple online sources when a user clicks a location.

---

## 🚀 Key Features

* [cite_start]**Interactive 3D Visualization:** Explore world events on a rotating 3D globe with clickable hotspots[cite: 61, 64].
* [cite_start]**AI-Powered Summaries:** Instantly generate concise, accurate summaries of local events using LLMs and LangChain[cite: 62, 95].
* [cite_start]**Real-Time Data Verification:** Utilizes an **MCP (Model Context Protocol)** server to fetch verified live data, ensuring accuracy over standard hallucinations[cite: 62, 96].
* [cite_start]**Smart Filtering:** Filter news by category (Politics, Sports, Economy) or search by specific keywords and locations[cite: 66, 67].
* [cite_start]**Personalized Alerts:** Subscribe to specific topics or regions and receive AI-curated email notifications[cite: 68, 103].
